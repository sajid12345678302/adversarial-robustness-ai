# Adversarial Robustness AI

## Overview
This project explores adversarial attacks and defense techniques in deep learning systems. It evaluates how small perturbations can affect model predictions and investigates methods to improve AI robustness.

## Features
- FGSM Adversarial Attack
- Robustness Evaluation
- Adversarial Training
- Deep Learning Security Analysis

## Research Motivation
Deep learning systems are vulnerable to adversarial attacks that can manipulate predictions using imperceptible perturbations. This project investigates trustworthy AI and secure model development.
